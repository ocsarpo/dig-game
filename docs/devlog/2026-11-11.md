# 2026-11-11 — Player의 격자 이동

프로젝트 실행 시 열리는 Scene을 `main.tscn`으로 지정했다. Main 아래 Ground와 나란히 `Player`(Node2D)를 두고 `player.gd`를 연결했다. 자식 Sprite2D에는 임시로 128×128 기본 아이콘을 사용했다. 배율 0.25라 화면에서는 32×32 크기로 보인다.

## 다음 위치를 구하고 경계 확인하기

Player의 `position`은 부모 Main 기준 좌표다. 시작점 (16, 16)은 32픽셀 이동 격자의 첫 칸 중심이다. 오른쪽 입력이면 (48, 16)을 다음 위치로 계산한다. Ground도 Main의 같은 원점을 사용하므로 이 값을 `ground.local_to_map(next_position)`에 전달해 타일 좌표로 바꿀 수 있다.

`ground.get_used_rect().has_point(map_position)`이 참일 때만 Player의 위치를 갱신한다. 이 검사는 배치한 타일을 모두 감싸는 사각형의 경계를 사용하므로 사각형 내부의 빈칸도 통과한다. Player의 이동 간격은 32픽셀이고 Ground의 TileSet 셀은 기본 16×16이어서, 한 번 이동하면 타일 좌표로는 두 칸 이동한다.

## 키를 누른 채 반복 이동하기

처음에는 `is_action_just_pressed()`로 한 번 누를 때 한 칸 이동했다. 현재는 `is_action_pressed()`로 타이머가 만료될 때 방향키 상태를 읽는다. `if/elif`로 방향 하나를 선택해 상하좌우로만 움직인다. 방향 입력으로 이동을 시도하면 경계에 막힌 경우에도 `move_timer`를 `MOVE_INTERVAL`인 0.15초로 되돌린다.

`_process(delta)`의 `delta`는 직전 프레임 이후 흐른 초다. 60 FPS라면 약 1/60초, 120 FPS라면 약 1/120초이며, 1초 동안 더하면 둘 다 약 1초다. 매 프레임 이 값을 타이머에서 빼므로 이동 간격을 초 단위로 정할 수 있다. 실제 이동 시점은 타이머가 0 이하가 된 프레임이다.

## 다음 실습
