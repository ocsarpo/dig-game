# 2026-11-21 — 굴착과 자원 판매 프로토타입

## 오늘 반영한 것

- 굴삭기 본체 체력과 굴착 내구도를 분리했다. 굴착 내구도는 100에서 시작하고, 흙은 작업 입력마다 1, 광물은 등급별 비용만큼 소모한다. 내구도가 부족할 때 작업을 막고 대상 칸과 HUD로 알린다.
- 굴착력을 1에서 시작해 강화 단계당 0.2씩 높일 수 있는 계산 구조를 두었다. 흙은 내구도 2, 석탄·구리·철은 각각 3·4·8이다. 강화 구매 기능은 아직 연결하지 않았다.
- 1스테이지의 흙 아래에 석탄·구리·철 광맥을 정해진 비율로 무작위 배치한다. 흙을 제거하면 광석이 드러나고 별도로 채굴한다. 광물의 무게와 판매가는 등급에 따른 고정값이다.
- 작업할 때 굴삭기 팔의 타격, 대상의 반짝임과 파편, 광석의 흔들림과 채굴 진행 표시를 넣었다.
- 지상 흙 두 줄을 비워 집과 상점 건물을 배치했다. 상점 근처에서 E로 열고 Esc로 닫는다.
- 상점에서 흙·석탄·구리·철을 각각 고르고 판매 수량을 조절할 수 있다. 전체 판매는 별도 항목을 선택하고 한 번 더 확인한다. 판매한 자원 무게는 줄고 돈은 누적된다. 자원마다 픽셀 아이콘을 표시한다.
- 적과 충돌해 굴삭기 체력이 줄면 화면이 한 번 붉어지고 짧게 흔들린다.

## 다음에 할 일

- 실제 플레이에서 굴착, 채굴, 상점 조작, 충돌 연출을 확인한다.
- 집에서 휴식할 때 날짜와 같은 스테이지의 새 맵으로 넘어가는 흐름을 구현한다.
- 운반 한도와 굴착 성능 강화의 가격과 효과를 정하고 상점에 연결한다.
- 2스테이지 이후 광물 분포와 적의 단계별 난이도를 정한다.

## 확인

- Godot 헤드리스 실행에서 새 스크립트 파싱 오류는 없었다. 기존 타일셋 경고는 남아 있다.
- 실제 플레이 검증은 아직 하지 않았다.
