# 게임 밸런스 설정

게임플레이 숫자와 조정할 값의 기준 문서다. `game-design.md`에는 규칙을, 이 문서에는 그 규칙에 쓰이는 수치를 둔다. `임시` 값은 플레이 후 조정한다.

## 자원과 운반

| 항목 | 값 | 상태 |
| --- | ---: | --- |
| 흙 블록 판매가 | 1원 | 임시 |
| 흙 블록 무게 | 1 | 임시, 가장 가벼운 자원 |
| 시작 운반 한도 | 50 | 임시 |
| 광물 무게와 판매가 | 미정 | 라운드가 오를수록 비싼 광물 비중 증가 |
| 운반 한도 확장 비용과 증가량 | 미정 | 상점 구매 |

## 플레이어와 집

| 항목 | 값 | 상태 |
| --- | ---: | --- |
| 굴삭기 시작/최대 체력 | 3 | 임시 |
| 접촉 시 굴삭기 피해 | 1 | 확정 |
| 접촉 시 적 피해 | 1 | 확정 |
| 집 시작 라이프 | 10 | 임시 |
| 집 공성 피해 | 1 | 확정 |
| 적의 집 공격 간격 | 3초 | 임시 |

## 적

| 항목 | 값 | 상태 |
| --- | ---: | --- |
| 흙 파괴 시 적 출현 확률 | 60% | 임시, 기존 30%의 2배 |
| 적 안전 구역 깊이 | 4칸 | 확정 |
| 출현 한 번당 적 수 | 1~3마리 | 임시 |
| 현재 체력 단계 | 2 / 4 / 6 | 임시, 전면 재설계 예정 |
| 현재 체력 단계별 출현 비중 | 50% / 30% / 20% | 임시, 전면 재설계 예정 |
| 다음 라운드의 적 강화량 | 미정 | 라운드별 난이도 설계에서 결정 |

## 흙과 집 포탑

| 항목 | 값 | 상태 |
| --- | ---: | --- |
| 흙 블록 파괴에 필요한 피해 | 2회 | 임시: 첫 피해는 반파 |
| 집 포탑 2단계 공격 간격 | 10초 | 임시 |
| 집 포탑 3단계 공격 간격 | 5초 | 임시 |
| 광물별 출현 확률과 라운드별 변화 | 미정 | 추후 설계 |
