# 게임 밸런스 설정

이미 구현된 수치 밸런스의 단일 기준은 [game_balance.gd](../game_balance.gd)다. 플레이 감각을 조정할 때는 이 파일의 값을 바꾸며, 개별 게임 스크립트에 같은 숫자를 다시 작성하지 않는다.

아직 기능과 함께 확정되지 않은 값만 여기에 기록한다.

## 추후 결정할 값

- 2스테이지 이후 광물 출현 비율
- 상점에서 운반 한도를 늘리는 비용과 증가량
- 상점 강화의 가격, 최대 단계, 효과
- 적 3단계의 전면 재설계와 라운드별 강화량
- 다음 라운드의 흙 내구도와 보상 상승량
- 집 포탑 공격 기능을 다시 추가할 때의 공격 간격과 위력

## 굴착 내구도 초안

- 굴삭기 굴착 내구도 기본값: 100
- 흙 굴착 입력 1회마다: 내구도 1 소모 (기본 흙 한 칸은 2회 입력, 총 2 소모)
- 광물 채굴 입력 1회마다: 해당 광물의 등급 수치만큼 내구도 소모
- 광물 한 개의 고정 운반 무게와 판매가도 같은 등급 수치로 설정
- 석탄 2, 구리 4, 철 8, 금 16, 에메랄드 32, 사파이어 64, 루비 128, 다이아 256
- 다이아 수치는 2배 진행 기준으로 256이다. 처음 적은 `258`은 산술상 2배 규칙과 맞지 않아 256으로 정리했다.
- 1스테이지 흙 아래 자원 분포: 일반 흙 70%, 석탄 매장 15%, 구리 매장 10%, 철 매장 5%
- 이후 스테이지마다 새 광물을 한 종류씩 추가하는 순서 초안: 금, 에메랄드, 사파이어, 루비, 다이아
- 스테이지별 광물 출현 비율은 고정하고, 광물의 맵 위치는 새 맵마다 무작위 배치
- 2스테이지 이후 광물 출현 비율은 미정
- 상점에서 굴착 내구도 최대치를 강화할 수 있다. 강화 비용과 증가량은 미정.
- 내구도가 0이면 추가 굴착/채굴을 멈추고, 파놓은 통로를 통해 상점으로 복귀한다.
- 새 작업일 시작 시 굴착 내구도는 강화된 최대치까지 회복한다.

## 채굴 입력 횟수

- 흙 블록 내구도: 2
- 기본 굴착력: 1
- 굴착력 강화: 단계당 +0.2, 5단계 강화 시 굴착력 2
- 기본 굴착력에서 흙 제거에는 Space 입력 2회, 석탄 채굴에는 3회 필요
- 프로토타입 채굴 내구도: 석탄 3, 구리 4, 철 8 (석탄 3은 확정; 구리/철은 우선 적용한 조정 가능 값)
- 필요한 입력 횟수는 블록 내구도와 현재 굴착력으로 결정
- 흙: 판매가 1, 운반 무게 1
- 광물 가격과 무게는 종류별 고정값이며 굴착력으로 채굴 입력 횟수가 바뀌어도 유지
