# 프로토타입 노트

## 이번에 검증할 내용

상하좌우 이동과 굴착, 두 작업 모드, 자원 운반, 위쪽 집의 방어와 적의 공성을 최소 프로토타입으로 확인한다.

## 필요한 최소 기능

- 흙 블록의 온전함/반파 상태
- WASD 상하좌우 이동. 흙을 파낸 빈 통로로 진입
- 흙 파기 모드에서는 흙만 파고 광물을 채취하지 않음
- 광물 채취 모드에서는 광물만 채취하고 흙은 파지 않음
- T 키로 두 모드 전환, 화면에 현재 모드 표시
- 굴삭기 헤드는 마지막 이동 방향을 향하며, E 키로 정면 블록을 현재 모드에 맞게 작업
- 흙을 파면 흙 자원이 운반 무게에 자동 적립
- 집 옆 상점에서 E 키로 상점 입장; 상점 밖에서는 E 키가 현재 모드 작업 수행
- 굴삭기 플레이어 외형
- 흙 파기/광물 채취 효과음
- 적 피격, 적의 집 공격, 집 폭발 효과음
- 적과 접촉할 때 적/굴삭기 체력 감소, 굴삭기 체력 0일 때 굴삭기 화염과 라운드 재도전
- 모드별 작업 대상과 피해/채취 처리
- 광물 출현과 인벤토리 획득
- 적 생성, 2번째 행 농성, 플레이어 도구 피격과 집 공격
- 집 포탑의 단계별 자동 공격
- 집 라이프와 적 공성 피해 주기는 [game-balance.md](game-balance.md) 기준
- 흙을 전부 제거했을 때 승리 표시

## 다음 작업 목록: 라운드·돈·상점

한 번에 전부 구현하지 않는다. 아래 순서대로 한 작업씩 기획하고, 플레이해서 확인한 뒤 다음 작업으로 넘어간다.

### 1. 라운드 종료와 재도전

- 집 라이프가 0이 되면 현재 라운드를 다시 시작한다.
- 흙을 모두 제거하면 라운드 성공 화면에서 `강화`와 `다음 라운드`를 고른다.
- 확인 기준: 집이 불타면 R을 눌러 같은 맵/라운드를 초기 상태로 재시작하고, 흙을 다 파면 상점/다음 라운드 선택지가 나온다.
- 선택지 화면까지만 이번 작업 범위로 삼고, 실제 상점과 라운드 진행은 후속 작업에서 연결한다.

### 2. 필드 아이템 제거와 광물 수집

- 공격 강화, 방어 강화, 폭탄, 하트 등 필드 아이템과 획득·표시·관련 효과음 로직을 제거한다.
- 흙 파기 모드와 광물 채취 모드를 분리한다. 전자는 흙만 파고, 후자는 광물만 채취한다.
- 흙과 광물을 무게 한도 안에서 운반하고, 현재 무게/최대 무게를 표시한다. 수치는 [game-balance.md](game-balance.md)를 기준으로 한다.
- 적 출현 확률과 안전 구역은 [game-balance.md](game-balance.md)의 값을 사용한다.
- 확인 기준: 기존 전투/회복 아이템은 나오지 않고, 각 모드가 지정된 대상만 처리하며, 적 출현 수치는 [game-balance.md](game-balance.md)를 따른다.

### 3. 라운드별 광물 분포

- 초기 라운드는 값싼 광물이 주로 나오고, 라운드가 오를수록 비싼 광물이 나올 확률을 높인다.
- 확인 기준: 라운드 번호에 따라 광물 종류별 출현 확률이 달라진다.

### 4. 상점에서 광물 판매

- 라운드 성공 뒤 `강화`를 선택하면 상점을 연다.
- 운반 중인 흙과 광물을 판매해 돈을 마련한다.
- 상점에서 운반 무게 한도를 구매해 늘린다.
- 상점은 집 옆에 두고 E 키로 입장한다.
- 확인 기준: 판매한 자원 무게가 줄고 정해진 판매액만큼 돈이 늘며, 무게 한도 확장이 적용된다.

### 5. 첫 상점 강화 3종

- 굴삭기 작업력
- 굴삭기 작업 속도
- 집 포탑 발사 간격 또는 포탑 해금
- 각 강화의 가격, 최대 단계, 실제 효과는 이 단계에 들어가기 전에 정한다.

### 6. 다음 라운드와 난이도 상승

- `다음 라운드`에서 새 필드를 시작하고, 기존 강화와 돈을 이어간다.
- 라운드가 올라갈수록 흙 내구도와 적 위협을 높이고 보상도 늘린다.
- 확인 기준: 다음 라운드 번호와 난이도가 오르고, 보상 변화가 화면/플레이에서 확인된다.

### 7. 나머지 상점 강화

- 굴착/광물 채취 능력 개발
- 집 라이프/방어력 강화
- 집 포탑 해금·발사 간격
- 집 포탑 공격력

## 구현 전에 결정할 질문

- 흙 속 광물의 표시 방식과 채취 입력/시간
- 광물 채취 입력과 채취 시간
- 광물별 무게, 한도 확장 비용/증가량
- 광물 종류, 종류별 판매 가격, 라운드별 출현 확률
- 상점 구매 후 라운드 선택 화면으로 돌아오는 버튼/흐름
- 다음 라운드별 흙 체력·적 수/체력·보상 상승 규칙
- 집이 불탄 재도전 시 진행 상태 초기화 범위
- 라운드 진행에 따른 적 성장과 적 3단계 재설계
