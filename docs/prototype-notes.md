# 프로토타입 노트

## 이번에 검증할 내용

좌우 이동과 흙 파괴, 미사일로 아이템 획득, 위쪽 집의 자동 방어 사격, 적의 상향 이동과 집 공성, 폭탄의 5×5 범위 효과를 최소 프로토타입으로 확인한다.

## 필요한 최소 기능

- 흙 블록의 온전함/반파 상태
- A/D 좌우 이동, 아래 방향 고정 미사일, 흙 블록 이동 차단
- 굴삭기 플레이어 외형
- 공격/방어 강화 획득 효과음
- 미사일 발사/폭발, 적 피격, 적의 집 공격, 집 폭발, 폭탄 폭발 효과음
- 미사일 단계별 흙 피해
- 흙 파괴 결과 확률과 아이템 획득
- 적 생성, 2번째 행 농성, 미사일 피격과 집 공격
- 집 포탑의 방어 단계별 자동 사격
- 집과 가장 가까운 적을 겨냥하는 곡선 미사일
- 집 라이프 10, 3초 공성 피해, 하트 회복 아이템
- 폭탄의 5×5 범위 제거
- 흙을 전부 제거했을 때 승리 표시

## 다음 작업 목록: 라운드·돈·상점

한 번에 전부 구현하지 않는다. 아래 순서대로 한 작업씩 기획하고, 플레이해서 확인한 뒤 다음 작업으로 넘어간다.

### 1. 라운드 종료와 재도전

- 집 라이프가 0이 되면 현재 라운드를 다시 시작한다.
- 흙을 모두 제거하면 라운드 성공 화면에서 `강화`와 `다음 라운드`를 고른다.
- 확인 기준: 집이 불타면 R을 눌러 같은 맵/라운드를 초기 상태로 재시작하고, 흙을 다 파면 상점/다음 라운드 선택지가 나온다.
- 선택지 화면까지만 이번 작업 범위로 삼고, 실제 상점과 라운드 진행은 후속 작업에서 연결한다.

### 2. 필드 아이템 제거와 돈 획득

- 공격 강화, 방어 강화, 폭탄, 하트 등 필드 아이템과 획득·표시·관련 효과음 로직을 제거한다.
- 흙을 팔 때 아이템 대신 돈을 얻고, 보유 금액을 표시한다.
- 적 출현 확률은 현재 30%의 두 배인 60%로 올린다. 4칸 안전 구역에서는 계속 적이 나오지 않는다.
- 확인 기준: 흙을 파도 필드 아이템은 나오지 않고, 돈이 지급되며, 안전 구역 밖에서 적 확률이 60%다.

### 3. 상점 진입과 구매 흐름

- 라운드 성공 뒤 `강화`를 선택하면 상점을 연다.
- 강화 구매 시 돈을 차감하고, 상점에서 나가면 라운드 선택으로 돌아온다.
- 확인 기준: 구매 가능 금액이 부족하면 살 수 없고, 구매 후 금액과 강화 상태가 유지된다.

### 4. 첫 상점 강화 3종

- 굴삭기 미사일 공격력
- 굴삭기 연사력
- 집 포탑 발사 간격 또는 포탑 해금
- 각 강화의 가격, 최대 단계, 실제 효과는 이 단계에 들어가기 전에 정한다.

### 5. 다음 라운드와 난이도 상승

- `다음 라운드`에서 새 필드를 시작하고, 기존 강화와 돈을 이어간다.
- 라운드가 올라갈수록 흙 내구도와 적 위협을 높이고 보상도 늘린다.
- 확인 기준: 다음 라운드 번호와 난이도가 오르고, 보상 변화가 화면/플레이에서 확인된다.

### 6. 나머지 상점 강화

- 미사일 능력 개발
- 집 라이프/방어력 강화
- 집 포탑 해금·발사 간격
- 집 포탑 공격력

## 구현 전에 결정할 질문

- 흙을 부술 때 돈은 매번 고정 지급할지, 종류나 깊이에 따라 달리할지
- 돈은 흙을 팔자마자 자동 획득할지, 미사일로 맞혀야 할 돈 아이템으로 둘지
- 집이 불탄 재도전 때 그 시도에서 번 돈을 보존할지
- 상점 구매 후 라운드 선택 화면으로 돌아오는 버튼/흐름
- 다음 라운드별 흙 체력·적 수/체력·보상 상승 규칙
