# 프로토타입 노트

## 이번에 검증할 내용

좌우 이동과 흙 파괴, 미사일로 아이템 획득, 위쪽 집의 자동 방어 사격, 적의 상향 이동과 집 공성, 폭탄의 5×5 범위 효과를 최소 프로토타입으로 확인한다.

## 필요한 최소 기능

- 흙 블록의 온전함/반파 상태
- A/D 좌우 이동, 아래 방향 고정 미사일, 흙 블록 이동 차단
- 굴삭기 플레이어 외형
- 공격/방어 강화 획득 효과음
- 미사일 발사/폭발, 적 피격, 적의 집 공격, 집 폭발, 폭탄 폭발 효과음
- 미사일 단계별 흙 피해
- 흙 파괴 결과 확률과 아이템 획득
- 적 생성, 맨 윗줄로 이동, 피격과 게임 오버
- 집 포탑의 방어 단계별 자동 사격
- 집과 가장 가까운 적을 겨냥하는 곡선 미사일
- 집 라이프 10, 3초 공성 피해, 하트 회복 아이템
- 폭탄의 5×5 범위 제거
- 흙을 전부 제거했을 때 승리 표시

아직 플레이 검증 전.

## 다음에 검토할 사항

실행 가능한 Godot 환경에서 조작과 화면 연출을 확인한다.

## 다음 기획 세션: 돈과 상점 루프 (미확정 아이디어)

- 필드에 놓이는 아이템과 공격/방어 강화 아이템, 관련 획득 로직을 제거한다.
- 적 출현 확률을 현재의 2배로 조정한다.
- 흙을 파면 아이템 대신 돈을 얻는다.
- 게임 오버로 끝내는 대신 다음 판으로 이어지는 진행 구조를 구상한다.
- 상점을 추가하고, 판 사이에 돈을 사용해 강화를 구매하는 방식을 검토한다.
- 상점 강화 후보: 굴삭기 공격력, 연사력, 미사일 능력 개발, 집 방어력, 집 포탑, 집 포탑 공격력.
- 다음에 정할 핵심 질문: 돈의 획득량과 사용처, 상점 방문 시점, 강화 가격/최대 단계, 판 사이 난이도 상승, 패배와 진행 초기화 방식.
